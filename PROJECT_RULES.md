# Правила проекта T-Echo Monitor

_Прочитай этот файл в начале каждого чата и следуй всем правилам._

---

## 1. Git и публикация

- **ВСЕГДА спрашивать перед `git push`** — не пушить без подтверждения пользователя
- После каждого коммита выводить сообщение: «Изменения закоммичены. Запушить в GitHub?»
- Если что-то пошло не так — **сразу дать команду на откат**:
  - `git reset --soft HEAD~1` — откатить коммит, сохранить изменения
  - `git reset --hard HEAD~1` — откатить коммит, удалить изменения
  - `git revert <hash>` — создать обратный коммит

## 2. Язык

- Общаться на **русском языке** (как пользователь)
- Комментарии в коде — на русском
- UI-текст в дашборде — на русском
- Имена переменных, функций, файлов — на английском

## 3. Архитектура проекта

- **Next.js 16** + TypeScript + Tailwind CSS 4 + shadcn/ui
- **Prisma ORM** + SQLite
- Python-мост `techo-bridge.py` для связи с Meshtastic-устройствами
- API-роуты в `src/app/api/`
- Компоненты дашборда в `src/components/dashboard/`
- UI-примитивы в `src/components/ui/`

## 4. Сеть Meshtastic

- Диапазон **433 МГц** (LPD433, Россия/СНГ)
- **Прошивка: 2.7.15** — всегда учитывать версию при работе с API и протоколом
- **BASE** — приёмник, всегда бодрствует (роль ROUTER/CLIENT_BASE)
- **TR01, TR02** — трекеры, цикл: 10 сек бодрствование → 60 сек сон
- Пакеты от трекеров приходят каждые ~70 секунд
- Режим реалтайм-мониторинга пакетов через pubsub

## 4.1. Актуализация документации Meshtastic

- **ВСЕГДА актуализировать документацию по Meshtastic** при работе с протоколом
- Использовать веб-поиск для проверки актуальных API, структур пакетов, параметров протокола
- При обновлении прошивки — проверять изменения в API и адаптировать код
- Документировать неочевидные решения и обходные пути в комментариях кода
- Ссылаться на официальную документацию: https://meshtastic.org/docs/
