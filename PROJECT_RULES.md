## 4. Сеть Meshtastic

- Диапазон **433 МГц** (LPD433, Россия/СНГ)
- **Прошивка: 2.7.15** — всегда учитывать версию при работе с API и протоколом
- **BASE** — приёмник, всегда бодрствует (роль ROUTER/CLIENT_BASE)
- **TR01, TR02** — трекеры, цикл: 10 сек бодрствование → 60 сек сон
- Пакеты от трекеров приходят каждые ~70 секунд
- Режим реалтайм-мониторинга пакетов через pubsub

## 4.2. Mesh-стратегия

- **Трекеры (TRACKER)** — конечные узлы, спят и экономят батарею, не ретранслируют пока спят
- **Надёжность mesh обеспечивается промежуточными узлами** (ROUTER / REPEATER), не трекерами
- При развёртывании в лесу — планировать размещение ROUTER/REPEATER между базой и трекерами
- Каждый промежуточный узел сокращает дистанцию прыжка → надёжнее через лес
- ROUTER — видимый backbone, всегда бодрствует, пакеты предпочитают маршрут через него
- REPEATER — невидимый ретранслятор, ноль overhead, чистая пересылка, идеален для дешёвых узлов на деревьях
- Рекомендуемый модем-пресет для леса: **LONG_MODERATE** (все узлы должны использовать одинаковый)
- hop_limit = 5-7 для леса (дефолт 3 — мало для пересечённой местности)
- Мокрая листва = -30..50% дальности → закладывать запас по количеству промежуточных узлов
